# C# & .NET Fundamentals Practice

A hands-on collection of small C# console applications created while learning programming core concepts, syntax, and logic through trial and error.

## 🚀 Key Topics Covered
- **Control Flow & Loops**: Practice with `while`, `for`, `foreach`, boundary conditions, and logic gates (`&&`, `||`).
- **Data Structures**: Working with arrays (`T[]`), dynamic lists (`List<T>`), and custom structures (`struct`).
- **Methods & Scope**: Method parameters, passing by reference (`ref`), and return types.
- **String Handling & Validation**: Custom input processing and simple validator logic.

## 🛠️ Tech Stack
- **Language**: C#
- **Framework**: .NET / Console Apps
- **IDE**: Visual Studio

## 📁 Projects Included
- **Password Validator**: Nested verification logic handling dynamic inputs.
- **Array / List Operations**: Methods calculating sum, handling dynamically resized bounds, and LINQ basics.
- **Data Modeling**: Basic entity representation using custom `struct` types.
